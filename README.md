## Proyectos destacados

### [Portfolio personal](https://github.com/Mariogarluu/Mario-Garcia-Luque)

Portfolio web profesional desarrollado con React, TypeScript, Vite y CSS moderno. Incluye
mi CV actualizado, experiencia, formación, habilidades y proyectos, con diseño responsive
y soporte para tema claro y oscuro.

### [LoL Fantasy](https://github.com/Mariogarluu/Lol-Fantasy)

Plataforma interactiva de esports de League of Legends con modo carrera, simulación de
partidos, gestión de equipos y el minijuego diario Pro-dle. Está construida con Angular,
TypeScript, Supabase y un enfoque offline-first.

🌐 **Demo:** [lol-fantasy-web.vercel.app](https://lol-fantasy-web.vercel.app/)

### Capri — *En proceso*

Asistente de escritorio 2D inteligente inspirado en una estética cyberpunk. El proyecto
explora un ecosistema conectado entre Windows y Android, con control por voz, telemetría
del equipo, automatizaciones para desarrollo y un dashboard web responsive.

> 🔒 **Estado:** actualmente privado y en desarrollo. Se publicará más información cuando
> el proyecto alcance una versión suficientemente estable.

### [Meta Force](https://github.com/Mariogarluu/Meta-Force-App)

Proyecto intermodular de DAM para la gestión de centros deportivos, desarrollado con
Angular, Express y PostgreSQL junto a [@sbuegonz00](https://github.com/sbuegonz00) y
[@sgarrui1201](https://github.com/sgarrui1201).

### [Bot de música para Discord](https://github.com/Mariogarluu/Bot-musica)

Bot de Discord con comandos y controles para reproducir música usando Node.js,
JavaScript y APIs externas.
